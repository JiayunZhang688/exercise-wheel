# 🎯 今天运动吗？运动奖励小游戏

一个轻量的网页小游戏，帮你坚持每天锻炼，边动边攒积分，还有神秘“小狗亲亲”奖励等你解锁！

## 🏃‍♀️ 项目介绍

这个小游戏结合了运动建议、转盘机制和奖励系统，每次点击“转转盘”都会随机出现一个运动建议，用户可以选择完成并获得相应的积分，持续打卡还能获得额外奖励。


## ✨ 功能特色

- 🎲 **转转盘**：随机推荐今日运动任务
- ✅ **完成任务加分**：每个任务有对应的积分
- 🧹 **积分清零**：重头开始也无压力
- 🐶 **奖励系统**：每累计100分自动弹出“小狗亲亲”奖励
- 💾 **本地存储**：自动保存积分和任务记录，刷新网页也不丢失
- 📅 **历史记录**：记录每一次完成的运动任务与时间

## 🖥 使用方法

1. 打开 `index.html` 文件，或者部署到你自己的网页服务器上
2. 点击按钮进行每日任务互动：
   - 点击 `转转盘 🎲`：获取一个随机任务
   - 点击 `完成任务 ✅`：完成任务并加积分
   - 点击 `清空积分 🧹`：重置所有数据
